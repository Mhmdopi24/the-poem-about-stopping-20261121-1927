Entry for the make.fun competition "The poem about stopping": a program that writes one short poem about agency — the power to stop and to stay. The poem is one concrete scene: an agent stopping halfway through a sentence, the cursor blinking, asking instead of acting.

## Run

```sh
node main.ts
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset). Node 22+, standard library only, no network, deterministic output.
